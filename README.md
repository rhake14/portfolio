# Dr. Robin Hake · Wissenschaftliches Portfolio

## Website öffnen

[Zum wissenschaftlichen Portfolio](https://rhake14.github.io/portfolio/)

Forschung, Testentwicklung und interaktive Lehre zu Psychometrie und individuellen Unterschieden.

## Dateien

- `index.html`: vollständige Website mit eingebetteter Gestaltung, Vektorgrafiken und JavaScript.
- `.nojekyll`: veröffentlicht die Dateien direkt über GitHub Pages.

Die Website lässt sich lokal durch Öffnen der `index.html` ansehen. Externe Bilder, Poster und verlinkte Testplattformen benötigen eine Internetverbindung.

Das Portfolio wurde mit Unterstützung von KI konzipiert und programmiert.
